# Victory Local — исходники прототипа

Кликабельный прототип внутреннего портала Victory Group. Бэкенда нет, данные — моки в `src/data.js`.

## Как открыть
- Готовая сборка: `dist/index.html` — открыть в браузере (фото лежат рядом в `dist/assets/photos`). Шрифт Onest грузится из Google Fonts.

## Как собрать
```
npm install
npm run build      # → dist/index.html
```
Нужен Node.js 18+.

## Структура
- `src/main.jsx` — роутинг (hash): `#home`, `#blog`, `#news-<id>`, `#people`, `#people-<dept>`, `#rooms`, `#forms`, `#kb`, `#kb-<id>`, `#store`, `#cards`
- `src/shell.jsx` — левое меню, шапка, поиск Ctrl+K, боковая карточка сотрудника, лоадер
- `src/pages.jsx` — главная, блог, новость, заглушки
- `src/people.jsx` — сотрудники (дирекция → отдел → группа), карточка сотрудника
- `src/rooms.jsx` — переговорки
- `src/forms.jsx` — бланки документов
- `src/kb.jsx` — база знаний
- `src/store.jsx` — магазин мерча
- `src/ui.jsx` — общие компоненты (Avatar, StatusPill, Button, Card, toast…)
- `src/data.js` — оргструктура, сотрудники, новости, переговорки, бланки, мерч
- `src/styles.css` — токены темы (тёмная/светлая) и Tailwind v4
- `assets/photos` — фото сотрудников
